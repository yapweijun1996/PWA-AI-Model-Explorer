# Goal / 目标

Publish a static PWA on GitHub Pages that makes it easy to **learn benchmark
terms, narrow model candidates and compare the exact source measurements**.

Primary user journey:

Learn a metric → explore source data → filter and sort → select 2–4 variants
→ compare measurements → record a workload hypothesis → verify it in real use.

Acceptance boundaries:

- Preserve the supplied snapshot without presenting it as current/live data.
- Keep cost, intelligence, speed and first-chunk latency meanings distinct.
- Explain missing/rounded values and chart exclusions.
- Work offline after initial preparation; no required account/server/API key.
- Visible version + install + explicit, safe update lifecycle.
- Learning progress and model notes stay local with a backup mechanism.
- Readable desktop/mobile UI, keyboard comparison and deterministic tests.
- Ship source, reproducible build, clear deployment guidance and verified evidence.

No claim that a general benchmark proves suitability for coding, ERP, tools,
privacy, reliability or a user's specific workload.
